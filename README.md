# Rookie Bakery

Trang bán bánh bằng React + Vite, lấy cảm hứng từ scrapbook, giấy xé và ảnh Polaroid.

## Chạy dự án

```sh
npm ci --cache /tmp/rookie-npm-cache
npm run dev
```

```sh
npm run build
npm run preview
```

Tính năng: lọc danh mục bánh, thêm vào giỏ, tăng/giảm số lượng, tính tổng và hoàn tất đơn trải nghiệm. Giao diện hỗ trợ điện thoại và máy tính.

Đơn hàng chỉ là minh họa; chưa có backend, thanh toán hoặc giao hàng. Giá và nội dung sản phẩm là dữ liệu mẫu.

Icon túi mua sắm: [Flaticon](https://www.flaticon.com/). Font được cài trong dự án qua Fontsource. Ảnh bánh được tạo riêng cho giao diện mẫu.
